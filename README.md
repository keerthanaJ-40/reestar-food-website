# reestar-food-website

Reestar is a simple, responsive restaurant website built using HTML and CSS.
It showcases a restaurant’s dishes, menu, and contact information in a clean, elegant layout — perfect for beginners learning web design fundamentals.

# Features

 Home Page – Displays restaurant introduction and featured dishes.

 Menu Section – Highlights dishes with images, names, and prices.

 Contact Form – Lets users reach out or make a reservation.

 Responsive Design – Works smoothly on desktop, tablet, and mobile.

 Pure HTML & CSS – No frameworks, just clean code and modern styling.

# Technologies Used

Technology	Purpose
HTML5	Page structure and content
CSS3	Styling, layout, and responsiveness
